# KRT Portfolio

A brutalist/minimal 3D sculpt & surface-design portfolio.

## Run locally
Open `index.html` directly in a browser.

## Put it online for free
1. Create a free GitHub account at github.com.
2. Create a new public repository, e.g. `krt-portfolio`.
3. Upload all files from this folder.
4. In GitHub: Settings → Pages → Deploy from branch → `main` → `/root`.
5. GitHub will give you a free `github.io` URL.
6. Add your custom domain in Pages → Custom domain.
7. At your domain registrar, add the DNS records GitHub shows you. This is usually a CNAME for `www` and/or GitHub's A records for the root domain.

## Replace content
- Replace `assets/*.svg` with your real renders (keeping the filenames), or update the image paths in `index.html`.
- Change `KRT`, email, social links and project text in `index.html`.
- Change fonts/spacing in `styles.css` if desired.

No paid hosting is required.
